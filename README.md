# Сервис создания коротких ссылок

Консольное приложение на Java. Оно создаёт короткие ссылки, ограничивает число переходов и автоматически удаляет ссылки по истечении срока действия.

## Запуск

Установите JDK 24 и выполните команду из корня проекта:

```bash
./mvnw
```

Maven Wrapper скомпилирует проект и запустит приложение.

Для открытия исходного URL нужен браузер в графической среде. Короткие адреса вида `short.local/lfls` вводятся в консоль приложения.

## Команды

| Команда | Действие |
| --- | --- |
| `create https://example.com 2` | Создать ссылку с лимитом в два перехода. Если число опущено, используется лимит из настроек. |
| `open short.local/lfls` | Открыть исходный URL в браузере. Можно также ввести `open lfls` или вставить короткий адрес отдельной строкой. |
| `list` | Показать свои ссылки, счётчики и сроки действия. |
| `limit short.local/lfls 3` | Изменить общий лимит. Он должен быть не меньше числа уже сделанных переходов. |
| `url short.local/lfls https://example.org` | Изменить адрес назначения. Счётчик и срок действия сохраняются. |
| `delete short.local/lfls` | Удалить свою ссылку. |
| `new` | Начать работу от имени нового пользователя. UUID появится при создании первой ссылки. |
| `user UUID` | Переключиться на пользователя с ранее выданным UUID. |
| `help` | Показать справку. |
| `exit` | Выйти из приложения. |

Попробуйте создать ссылку командой `create https://example.com 1`. Сохраните выданный UUID и вставьте полученный короткий адрес в консоль. Первый переход откроет страницу и исчерпает лимит. Повторный переход будет заблокирован. После перезапуска введите `user UUID`, подставив сохранённое значение, затем выполните `list`.

Изменять и удалять ссылку может только её владелец. Один и тот же исходный URL можно сократить несколько раз, каждый раз с новым кодом. Переход засчитывается после успешной передачи адреса браузеру. При исчерпании лимита или срока действия приложение уведомляет владельца. Уведомления других пользователей сохраняются до переключения на их UUID.

## Настройки и хранение

Настройки находятся в `shortener.properties`.

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `ttl.seconds` | `86400` | Срок действия новой ссылки в секундах. |
| `cleanup.seconds` | `1` | Интервал фоновой очистки в секундах. |
| `limit.default` | `10` | Лимит переходов, если он не указан. |
| `limit.max` | `1000` | Максимальный лимит переходов. |
| `short.prefix` | `short.local/` | Префикс коротких адресов. |
| `data.file` | `data/links.json` | Путь к JSON-файлу. Относительный путь считается от каталога файла настроек. |

Ссылки, UUID пользователей, счётчики и ожидающие уведомления сохраняются в JSON между запусками. Срок действия определяется при создании ссылки. Просроченная ссылка блокируется при обращении, очистка происходит в фоне.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| [Main.java](src/main/java/Main.java) | Запуск приложения, фоновой очистки и открытие браузера. |
| [Console.java](src/main/java/Console.java) | Чтение команд, вывод справки и уведомлений. |
| [Shortener.java](src/main/java/Shortener.java) | Создание коротких кодов, лимиты, сроки и права владельца. |
| [Settings.java](src/main/java/Settings.java) | Чтение и проверка настроек. |
| [Storage.java](src/main/java/Storage.java) | Загрузка и запись JSON. |

## Тестирование

```bash
./mvnw test
```
Первая команда запускает 17 проверок, в том числе сценарий работы через консоль. Проверяются уникальность кодов, права владельца, лимиты, TTL, уведомления и сохранение состояния между запусками. Для проверки открытия адреса тесты подставляют имитацию браузера.

```bash
./mvnw verify
```
Вторая команда дополнительно собирает JAR и проверяет стиль исходников и тестов через Checkstyle. Эту же команду запускает GitHub Actions при отправке изменений
